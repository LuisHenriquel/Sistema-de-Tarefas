# 📝 Sistema de Gerenciamento de Tarefas em Java

Este é um projeto simples de gerenciamento de tarefas feito em **Java**, ideal para praticar manipulação de arquivos e entrada de dados via terminal.

## ✨ Funcionalidades

- ✅ Adicionar tarefas
- ❌ Remover tarefas
- ☑️ Marcar tarefas como concluídas
- 📋 Listar todas as tarefas

As tarefas são salvas em um arquivo `tarefas.txt`, utilizando `BufferedReader` e `BufferedWriter` para leitura e escrita.
